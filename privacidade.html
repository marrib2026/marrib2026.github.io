Política de privacidade

Ferramenta pessoal de organização. Vigente desde 12 de outubro de 2026.

Quem usa

Este é um aplicativo de uso pessoal. Ele é usado apenas pelos titulares das contas Google que o autorizaram e não é oferecido a terceiros.

Que dados do Google o aplicativo acessa

O aplicativo pede uma única permissão do Google Drive: acesso aos arquivos que ele mesmo cria ou que o usuário abre com ele. Ele não acessa os demais arquivos do Drive, nem e-mails, contatos, agenda ou dados de perfil além do necessário para a autorização.

Como os dados são usados

Os dados são usados só para criar, ler e atualizar esses arquivos, para os próprios usuários que autorizaram o aplicativo.

Compartilhamento

Os dados não são vendidos, não são compartilhados nem transferidos a terceiros e não são usados para publicidade. Nenhuma pessoa lê esses dados além dos próprios usuários. Os dados não são usados para desenvolver, melhorar ou treinar modelos generalizados de inteligência artificial ou de aprendizado de máquina.

Armazenamento e segurança

Os arquivos permanecem no Google Drive do próprio usuário. As credenciais de acesso ficam guardadas de forma cifrada, em infraestrutura controlada pelos próprios usuários.

Como revogar

O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/connections.

Uso Limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Contato

Pelo e-mail de suporte exibido na tela de autorização do Google.
